Resource folder
images/instagram/ : copy Instagram avatars here. Example @jin -> jin.jpg
images/tiktok/    : copy TikTok avatars here.
images/youtube/   : copy YouTube avatars here.
images/sample/    : local fallback avatars used only when creator image is missing.
fontawesome/css/fa-local.css : local FA-compatible icon stylesheet.

The dashboard tries the creator-specific local image first, then a local sample avatar.
