5-Feature Model Logic
=====================

Profile Fit:
  ProfileFit = w_brand * BrandScore + (1 - w_brand) * CampaignScore

Content Fit:
  ContentFit = 0.50 * LuxuryRatio + 0.30 * JewelryRatio + 0.20 * FashionRatio

Campaign History Score:
  ExperienceScore = min(PastCampaignCount / 10, 1)
  HistoryScore = 0.30 * ExperienceScore + 0.70 * PastCampaignSuccessRate

Model Features:
  [ProfileFit, ContentFit, HistoryScore, EngagementRate, log1p(Followers)]

Scenario Fit (business sensitivity):
  ScenarioFit = w_profile * ProfileFit + w_content * ContentFit + w_history * HistoryScore
  w_history = 1 - w_profile - w_content

Final Ranking Score:
  FinalScore = 0.50 * LogisticRegressionProbability + 0.50 * ScenarioFit

Primary ranking:
  Sort descending by FinalScore.
  Therefore Profile / Content / History slider changes can re-order creators.
  Logistic Regression coefficients themselves are not overwritten by the business weights.

Decision Tree:
  Same five features; max_depth controlled by Tree Depth slider.
  Suitable/Not Suitable uses leaf probability compared with Suitable Threshold.
